# Link Up

A Flutter application (Link Up).

## Quick start

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Fetch dependencies:

```bash
flutter pub get
```

3. Run the app on an available device or emulator:

```bash
flutter run
```

4. Run tests:

```bash
flutter test
```

Notes:
- This repository includes a recommended `.gitignore` to avoid committing build outputs and local SDK settings.
- A simple GitHub Actions workflow is included at `.github/workflows/flutter.yml` to run `flutter analyze` and `flutter test` on push/PR.
